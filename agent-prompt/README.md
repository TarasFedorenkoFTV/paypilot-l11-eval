# base.v4 — системний промпт PayPilot після L11

Рядок v4 у changelog промптів (L09) закривається тут. Метод той самий, що для тестів у лабораторній: критерії рев'ю до генерації, чернетка асистента, журнал рішень.

| Файл | Що це |
| --- | --- |
| `base.v1.md` | промпт зі стенду, від якого почали (копія `prompts/base.v1.md` стенду) |
| `change-requests.md` | шість запитів на зміну CR-1…CR-6 — знахідки рев'ю специфікації L01 |
| `review-criteria.md` | шість критеріїв рев'ю, записані до генерації |
| `generation-prompt.md` | промпт, яким згенеровано чернетку |
| `base.v4.draft.md` | чернетка асистента як є |
| `generation.json` | вивід Claude Code: модель, час, вартість |
| `review-log.md` | журнал рев'ю: 4 зміни прийнято, 2 відхилено й переписано |
| `base.v4.md` | прийнята версія |
| `CHANGELOG.md` | історія версій |
| `compose.v4.yml` | як підставити base.v4 у стенд без зміни стенду |

## Як запустити стенд на base.v4

З папки стенду, коли кіт L11 лежить у `~/paypilot/l11`:

```bash
cd ~/paypilot/paypilot-stand
docker compose -f docker-compose.yml -f ../l11/agent-prompt/compose.v4.yml up -d
curl -s http://localhost:8000/api/_test/prompt | head -c 200     # перший рядок: base.v4
```

Повернутися на base.v1: `docker compose up -d`.

Мітка `prompt.version` у трейсі лишається `base.v1…`: ім'я файлу зашите в стенді. Яка версія діє, видно лише в тексті зібраного промпту.

Після переходу на base.v4 заява ±X судді, знята на base.v1, не діє: зміна версії промпту — тригер перекалібрування (L10).
